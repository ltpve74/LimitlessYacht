Home-screen app & notifications

Tracker works as an app on Android and iPhone (no App Store). Install once, then open from the home screen for full screen and better alerts.

Android (Chrome)
  1. Open this page in Chrome
  2. Tap ⋮ (top right) → Install app or Add to Home screen
  3. Confirm Install / Add
  4. Open Tracker from the home screen (not the browser tab)
iPhone / iPad (Safari)
  1. Open in Safari (not Chrome)
  2. Tap Share → Add to Home Screen → Add
  3. Open Tracker from the home screen

Alerts (invoice issued/paid, roster updates) work best after install. On Android Chrome may offer a one-tap install banner; use the steps above if you don’t see it.
